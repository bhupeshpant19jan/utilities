# Package contents

This package contains the complete Nationwide US Investment Area Discovery materials.

- `README_US_Investment_Area_Discovery.html` — browser-friendly quick-start and output guide.
- `README_US_Investment_Area_Discovery.md` — editable Markdown version of the guide.
- `SKILL_Nationwide_Investment_Area_Discovery.md` — guided first-run setup and recurring research workflow.
- `US_Investment_Area_Discovery_Master_Prompt.md` — full criteria, gates, scoring weights, evidence standards, workbook schema, and quality checks.

## Getting started

1. Open the HTML README for a short overview.
2. Keep all four files together in the same folder. The skill references the master prompt by filename.
3. Use the skill instructions to run the first-time conversational setup wizard.
4. Confirm the setup before the first full research run.

## Scope

This is a market/area discovery package: it identifies and ranks metros, geographic clusters, and ZIP codes. It does not replace property-level listing research, underwriting, or address-specific due diligence.

The files are shareable reference materials. Sharing this ZIP does not install the skill into another person's ChatGPT account or configure an automation for them; they must add/use the instructions in their own environment.
